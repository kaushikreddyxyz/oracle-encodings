# Graft direction recovery

Primary question: do unsupervised dictionaries and supervised linear methods recover the known injected edge directions?

Design: fixed and learned grafts; grid sizes 5–10; model seeds 0 and 1. Analyze PATH_START immediately after the layer-0 injection (primary), and after block 0 (secondary). Fit on 16,000 newly generated random-DFS mazes (seed 19001), select feature labels/scales on 4,000 separate mazes, and evaluate on the existing 3,000-maze distance evalsets (seed 4321). Never train on difference-eval mazes.

Methods: ReLU + L1 SAE, BatchTopK SAE, Matryoshka BatchTopK SAE with nested prefix reconstruction, and an unrolled residual-greedy Matching Pursuit SAE. Custom compact implementations, not claims of tuned reference-library reproductions. Linear methods: difference of means, ridge readout, logistic readout, and multivariate generative OLS. SAEs use 1,024 atoms (4x), k=16 where applicable; report actual held-out sparsity/reconstruction and inactive atoms. Signed direction comparisons account for open-vs-wall polarity. Report nearest-atom and label-selected cosine separately, plus one-to-one assignment, random dictionaries of equal size, and shuffled edge assignments.

Identifiability: every DFS maze has n²−1 open edges, so the edge labels have a constant-sum constraint. Absolute individual graft columns are not fully identifiable from natural-maze activations: a common vector added to every column is absorbed into the intercept. Report both raw columns and the identifiable zero-mean-across-free-edges gauge. Forced boundary edges are excluded. At the injection site, PATH_START has constant token/position embedding, so the primary activation is an exact linear mixture; the block-0 secondary analysis tests recovery after nonlinear processing.

Interventions: start with the actual A graft; add recovered edge-direction edits for B−A at the corresponding site, from ADJLIST_END onward, including decoding. For each edge, select the SAE atom with greatest absolute validation label correlation, without using true graft weights; several edges can select the same atom. Fit per-edge scales by generative regression on training activations projected onto the selected directions. Choose global strength on 20 validation-eval base mazes, then evaluate on disjoint 60 test base mazes at levels 0, 1, 4, 8, 12, 13. Keep all variants of a base maze in one split. Ground-truth graft replacement, unedited model, and generative OLS are controls. Aggregate uncertainty by base maze/model rather than treating variants as independent.

Reference algorithms:
- https://github.com/saprmarks/dictionary_learning (ReLU, BatchTopK, Matryoshka)
- https://github.com/KempnerInstitute/overcomplete/blob/main/overcomplete/sae/mp_sae.py (Matching Pursuit)

Legacy steering source was recovered read-only from `../maze_injection_backup_20260806.tar.gz`; reference copies are under `reference/`. The active mzsteer-pilot pod belongs to separate ongoing work and is not part of this campaign.


Final split audit: seed separation alone was insufficient at grid 5 and, rarely, grid 6. Those two shards were discarded and rerun after exact connectivity deduplication (train vs validation, and all fitting graphs vs every A/B graph in the frozen difference evalsets). The initial runs are isolated under `initial_overlap_runs/` and excluded from all final aggregates. Grids 7–10 had zero observed graph overlaps. The archived legacy training/validation/test connectivity split also had zero overlaps.

Legacy protocol: two current grid-6 baseline checkpoints, 8,000 fitting + 2,000 validation mazes; linear-probe accuracy swept over all 12 resid_post layers at PATH_START. Evaluate layer 0 and each model's best logistic-probe layer. Use the archived 4,522-edit corpus over 600 mazes, selecting 30 validation and 100 test base mazes, with every edit of a base maze in the same split. The original simultaneous class-coordinate steering is applied from ADJLIST_END onward, including decoding; strengths 1, 4, 8 selected on validation solve rate. Report blocked-edge crossing, opened-edge use, target reach, and valid target-maze solve rates by edit family. These are replications of the protocol on the current checkpoints, not assertions of identical historical numerical results.

Sensitivity: an additional grid-10 model-seed-0 study for fixed/trainable grafts repeats each SAE with seed 202 at the primary budget, and with seed 101 and k=64 (ReLU L1=1 instead of .1). These tests are reported separately rather than used to choose the primary result by ground-truth alignment. The primary SAEs use seed 101, 2,000 Adam steps, 512 examples per step, and learning rate 1e-3. Our compact training does not include auxiliary dead-latent losses or a comprehensive hyperparameter search. The primary ReLU baseline can be substantially denser than k-sparse methods; figures report measured sparsity.

Rollout limits: 2n²+4 new tokens for the difference experiment (capped by context length), and 76 new tokens for the archived grid-6 experiment. All comparisons within each experiment share this limit. The original `eval_distance.py` used n²+2, so these are freshly computed, internally matched comparisons rather than copied scores.

The stronger dictionary null samples equally many unit atoms in the span of the generative edge-to-activation coefficients (rank determined by relative singular-value threshold 1e-5), averaging three draws. This controls for the easy best-of-many match in a low-dimensional, label-predictable subspace. `subspace_nulls.json` records these derived controls separately from the hash-verified raw pod outputs. Paired intervention bootstrap intervals resample whole base mazes within each grid, jointly across both model seeds and all maze variants.
